# Unity URP Stylized Post-Processing Experiments # 

A collection of experimental custom post-processing effects built for Unity URP, focusing on stylized NPR rendering such as Difference of Gaussians outlines, Extended DoG (Garrett Gunnell), Kuwahara painterly filter, Pixelization, Dithering, Posterization, Palette-based shading, and more.

The project serves as a personal sandbox to study:

Advanced RenderGraph workflows in URP

Custom ScriptableRendererFeature architecture

Efficient post-processing pipeline design

Shader optimization, profiling, and variant comparison

Combining multiple NPR filters to achieve unique stylized aesthetics
